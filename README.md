## Features

- Unlimited messages
- Allow all character in chat
- No cooldown

# Releases

ChatUs is compatible with desktop releases of Among Us. This includes Steam, Epic Games and itch.io. We do not support cracked versions of Among Us.

|                                       Among Us Version                                        | ChatUs Version |                                        Links                                        |
|:---------------------------------------------------------------------------------------------:|:-----------------:|:-----------------------------------------------------------------------------------:|
|                                           `v19.0.0`                                           |   `v2026.10.25`   | [Download](https://github.com/Isax820/ChatUs/releases/tag/v2026.10.25) |
